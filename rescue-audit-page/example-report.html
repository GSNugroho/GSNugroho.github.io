critical APP_DEBUG is enabled in production

check: config · estimated fix: 0.25 h

Debug mode leaks stack traces, environment variables and database credentials on any error page. Set APP_DEBUG=false in the production .env.

high 1 model(s) set $guarded = [] (every column is mass-assignable)

check: models · estimated fix: 1 h

Combined with Model::create($request->all()) a user can set is_admin, role, user_id or price from the form. Replace with an explicit $fillable list, or always pass $request->validated() with only the intended keys.

check: models · estimated fix: 1 h

Whatever the client posts ends up in the database if the model allows it. Use $request->validated() or $request->only([...]).

high Session cookie is not marked Secure (SESSION_SECURE_COOKIE)

check: config · estimated fix: 0.25 h

Without the Secure flag the session cookie can be sent over plain HTTP and intercepted. Set SESSION_SECURE_COOKIE=true once the site is served over HTTPS.

medium 1 view(s) access a relation inside a loop that is never eager-loaded

check: nplus1 · estimated fix: 0.5 h

Each iteration fires an extra query, so a page with 100 rows runs 100+ queries. Add ->with('relation') to the query in the controller, or $collection->load(...). Verify with Laravel Debugbar or Model::preventLazyLoading() in local. (Heuristic: the relation name was not found in any with()/load() call under app/.)

medium 41 of 44 route(s) have no rate limiting (throttle)

check: routes · estimated fix: 1 h

Without throttle middleware, login forms, OTP endpoints and search pages can be brute-forced or used to exhaust the server. Apply throttle:60,1 (or a named limiter via RateLimiter::for) to the web/api groups, and a stricter one to login/OTP routes.

  • POST /login
  • POST /otp/verify
  • GET /search
  • POST /password/email
  • GET /products
